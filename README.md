
# 🍇 GRAPE ICT Club Hub

A high-performance analytics dashboard for managing your ICT club.

## 🚀 Deployment to Vercel

1. **GitHub**: Push these files to a new GitHub repository.
2. **Vercel**: Import the repository into Vercel.
3. **Environment Variables**: 
   - Add `API_KEY` with your Google Gemini API key.
4. **Supabase**:
   - Create a project at [supabase.com](https://supabase.com).
   - Go to the **SQL Editor**.
   - Paste the contents of `schema.sql` and click **Run**.

## 🛠️ Local Development

```bash
npm install
npm run dev
```
